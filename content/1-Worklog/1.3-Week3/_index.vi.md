### Mục tiêu tuần 3:

* Thiết lập cấu trúc dự án backend và môi trường phát triển.
* Phát triển các RESTful API dựa trên kiến trúc và API contract đã lên kế hoạch ở Tuần 2.

### Thành tích tuần 3:

* Thiết lập dự án backend với cấu trúc rõ ràng, dễ bảo trì.
* Triển khai các API endpoint đúng theo contract đã thống nhất trong giai đoạn lên kế hoạch kiến trúc.
* Triển khai xác thực/phân quyền sử dụng JWT.
* Hoàn thành API CRUD cho các đối tượng chính.
* Kiểm tra các API hoạt động đúng bằng Postman và chuẩn bị tài liệu ban đầu trước khi tích hợp với frontend.
