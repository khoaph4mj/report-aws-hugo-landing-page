# Work Log Introduction

During my internship at FCAJ, I was part of the team building a web application deployed on AWS, mainly focusing on the backend and database side of the project, while also getting involved in deployment and monitoring toward the later stages.

This worklog covers an 11-week internship program, from 01/06/2026 to 14/08/2026 (roughly 2.5 months). Because my role centered on the backend and data layer, I organized my work so that backend development and database integration came right after the architecture design phase, with frontend integration support following once the APIs and database were in place. Over this period, I got hands-on with AWS cloud services, took part in requirement analysis and system design, built backend APIs, worked on database design and integration, supported the frontend team's integration needs, helped deploy the application to AWS, supported system monitoring, and contributed to the project's technical documentation.
