### Mục tiêu tuần 5:

* Hỗ trợ nhóm frontend tích hợp với các API backend và cơ sở dữ liệu đã hoàn chỉnh.
* Thống nhất và xử lý các sai lệch về dữ liệu hoặc contract phát hiện được trong quá trình tích hợp thực tế.

### Các nhiệm vụ cần thực hiện trong tuần này:
| Ngày | Nhiệm vụ | Ngày bắt đầu | Ngày hoàn thành | Tài liệu tham khảo |
| --- | --- | --- | --- | --- |
| 2 | - Chia sẻ tài liệu API đã hoàn thiện với nhóm frontend và giải thích các endpoint hiện có | 29/06/2026 | 29/06/2026 |  |
| 3 | - Hỗ trợ nhóm frontend kết nối các lệnh gọi API thật với backend, thay thế dữ liệu giả lập trước đó | 30/06/2026 | 30/06/2026 |  |
| 4 | - Gỡ lỗi và xử lý các sai lệch về định dạng dữ liệu hoặc response phát hiện trong quá trình tích hợp frontend | 01/07/2026 | 01/07/2026 |  |
| 5 | - Cùng nhóm frontend rà soát luồng xác thực end-to-end (đăng nhập/đăng ký với backend thật) | 02/07/2026 | 02/07/2026 |  |
| 6 | - Thu thập phản hồi từ nhóm frontend về khả năng sử dụng của API và điều chỉnh một số chi tiết nhỏ ở backend nếu cần | 03/07/2026 | 03/07/2026 |  |

### Thành tích tuần 5:

* Hỗ trợ thành công nhóm frontend chuyển từ dữ liệu giả lập sang tích hợp thật với backend/cơ sở dữ liệu.
* Phát hiện và sửa một số sai lệch về định dạng dữ liệu giữa phản hồi của backend và kỳ vọng của frontend.
* Xác nhận luồng xác thực hoạt động đúng end-to-end với backend thật.
* Điều chỉnh một số chi tiết nhỏ ở backend dựa trên phản hồi từ nhóm frontend để cải thiện khả năng sử dụng API.
* Đạt được trạng thái ổn định khi frontend và backend đã tích hợp hoàn chỉnh và hoạt động cùng nhau.
