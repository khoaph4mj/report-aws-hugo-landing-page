* Hoàn thiện sơ đồ cơ sở dữ liệu và khởi tạo database instance.

### Thành tích tuần 4:

* Hoàn thiện và chuẩn hóa sơ đồ cơ sở dữ liệu dựa trên thiết kế API thực tế.
* Khởi tạo database instance cho môi trường local và cloud.
* Tích hợp ORM/ODM và kết nối toàn bộ API CRUD với cơ sở dữ liệu thật.
* Triển khai script seed dữ liệu và migration để đồng bộ môi trường giữa các thành viên trong nhóm.
* Xác nhận kết nối cơ sở dữ liệu ổn định và tối ưu các truy vấn quan trọng — backend lúc này đã hoạt động trọn vẹn và sẵn sàng để tích hợp với frontend.
